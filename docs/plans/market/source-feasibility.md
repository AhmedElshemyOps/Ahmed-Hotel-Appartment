## Admission checklist for an actual connector

Require a documented agreement permitting this particular pricing-analysis use, storage, derivative recommendations and (separately) exports; a provider sample; geographic coverage; exact apartment-type and guest context; dated available offers; explicit taxes/fees; unmodified source timestamps; identity-matching rights; and a refresh/quota/retention/cost schedule. Review permission evidence and expiry in the app before ingestion. Source permission entered by the GM is an administrative attestation, not an automated legal validation.

Automated collection is restricted to an installed connector with fixed permitted endpoints and server-managed credentials. No user-entered source URL is fetched. Sources can be revoked; revoked/expired/stale observations cannot support new recommendations. Observations can remain visible as excluded historical evidence within permitted retention, but must never be presented as current prices.
